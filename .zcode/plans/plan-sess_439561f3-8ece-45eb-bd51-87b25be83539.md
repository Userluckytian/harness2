## 目标
生成**一个自包含的静态 HTML 原型**，把 GUI（Web/桌面共用那套）在每个页面与交互下的样子画出来，供你直观评审。**单文件、零依赖、双击即开、无外部网络请求。**

说明：这是**视觉原型**，不是实现——用纯 CSS 变量 + 原生 JS 近似 ZCode 的观感（因为 Tailwind 还没装）。色值取自 ZCode `Zai Light` / `Zai Dark` 的**真实 token**。

## 产出物
`design/prototype-zcode.html`（单文件，与既有 `design/prototype-v5.html` 等命名风格一致）

## 原型必须覆盖的内容

### A. 布局骨架（可交互）
- 顶栏：品牌 + 侧栏开关 + 右栏开关 + 设置 + 状态徽标
- 左栏：新任务、命令中心入口、Workspace/Project/Conversation 分区、会话列表（含运行/未读旗标）、底部导航（自动化/插件商店/设置）、账号区
- **可拖拽**的 1px 分栏条（含 hover 态）
- 内容区**嵌套分栏**：对话 | 浏览器 · 对话 | 终端
- 右栏：**标签条**（可切换、可关闭、hover 态）+ 面板内容
- **侧栏折叠成轨道**态

### B. 页面与视图（可切换）
1. **对话视图**：空态（建议提示）/ 有内容态；消息气泡（用户/助手）、思考块、**工具卡三态**（running 转圈 / done / failed）、diff 卡、内联审批卡、composer（模型·effort·mode 选择器 + 附件 + 发送）
2. **轨迹视图**：时间概览 + 记录表 + 检查器
3. **右栏九个标签**：计划 / 任务 / 审批 / 变更 / 工作区 / 文件 / 浏览器 / 终端 / 子代理
4. **设置页（整屏）**：68px 图标栏 + 268px 导航 + 内容；分区按 ZCode 的分组（通用 / 外观 / 模型与提供方 / 浏览器 / Computer Use / 快捷键 / 工作区搜索 —— 记忆 / 子代理 / 插件 / MCP / 技能 / 命令 / 自动化 / Hooks —— 用量）；外观分区含主题选择 + 字号 + 代码预览
5. **命令中心**（Ctrl+K）：commands / conversations / files 三分区 + 搜索过滤

### C. 组件与状态（可交互）
- 按钮全变体（default / outline / secondary / ghost / destructive / warning / link）× 全尺寸
- 输入框（默认 / hover / focus）、下拉选择、开关、Tabs、Badge、Kbd
- **对话框**（遮罩 + 圆角 + 阴影）、确认删除框
- **下拉菜单**（含分组与 destructive 项）
- **Tooltip**（hover 显示）
- **Toast**（点击弹出）
- 滚动条样式、Spinner、空态、加载中、错误态
- 审批卡交互（Allow / Deny 点击反馈）

### D. 主题（可切换）
- `Zai Light` / `Zai Dark` / **跟随系统** 三选切换
- 用 ZCode 真实色值：亮 背景 `#f8f8f8`、卡片 `#ffffff`、侧栏 `#f0f0f0`、边框 `rgba(13,13,13,.1)`、accent `#ebf4ff`、品牌纯黑；暗 背景 `#161616`、卡片 `#2b2b2b`、边框 `rgba(255,255,255,.1)`、accent `#001d3d`、品牌纯白
- 字号体系按 ZCode（基准 14px，`text-ui-*` 刻度）、间距 4px 基准、圆角按嵌套降级、控件默认高 28px

### E. 顶部的"评审工具条"
页面顶部加一个原型专用工具条（不属于真实 UI，标注清楚）：**主题切换 + 快速跳到各页面/状态**，方便你逐屏检查。

## 验收标准
- `design/prototype-zcode.html` 落盘，浏览器直接打开可用
- 零外部依赖、零网络请求（自包含 CSS/JS，图标用内联 SVG 或 Unicode）
- 上述 A–E 清单逐项可在页面上点到
- `git status` 仅显示该文件新增，`packages/**` 零改动
- 不改任何配置、不加依赖、不碰现有文件

## 明确不做
- 不改 `packages/**`、不动构建配置、不引依赖（Tailwind 实施留到后续阶段）
- 不写参考文档（本轮只做视觉原型；文档方案等你评审完原型再定）
- 不做 git commit / push
