编辑器外观

统一"代码怎么显示"；但 harness2 不做内置编辑器。

为什么不做内置编辑器：真实编辑交给外部编辑器（VS Code / JetBrains）成本最低，也能避开与「审批 / 文件快照 / undo」三条链路的冲突。我们只统一代码的呈现，并提供"在外部编辑器打开"。
