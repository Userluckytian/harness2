## 与当前架构的关系

当前分层：`core`（agent 内核 + 服务面）→ `cli` / `desktop` / `gateway` 三个消费端。
远期「多端」预期新增 `web` 端；「插件市场」预期扩展 `plugins` 面；「插件式语言」预期改变插件加载机制。以上均需在冻结解除后单独立项评估。
