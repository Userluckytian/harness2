# 2026-10-12 阶段 Z8 · 侧栏信息架构对齐（ZCode）

> 上位：`docs/ai-framework/plans/2026-10-10-phase-zcode-ui-overhaul.md`（Z0–Z7）。
> 触发：与 **ZCode 官方 web** 实时对照（配方见 `2026-10-11-phase-Z7-closeout.md` §6.2）发现侧栏差异——**ZCode 16 个交互项 vs 我们 7 个**（实测见 `docs/issue-log/2026-10-11.md` §47）。
> 用户决策（2026-10-12）：**先补骨架信息架构**（不含自动化视图/文件树/插件市场）。

## 1 目标与范围

**做**（权威规格 `docs/refs/refs-zcode-layout.md` Z-07～Z-11）：

1. **任务工具栏**（Z-07 #5）：视图模式分段（`分组` / `项目`）+ 全部展开/收起 + 筛选排序 + 归档按钮；偏好默认 `organizeBy: project` / `sortBy: updated`（Z-08）。
2. **Projects 区 + Conversations 区**（Z-07 #7/#8）：双分区，各可折叠、默认展开（Z-08 的 workspace 展开态默认展开）。
3. **Pinned 区**（Z-07 #6）：**有置顶项才显示**（空则 return null），超 20 条折叠。
4. **会话项细节**（Z-09）：左侧 16px leading 槽（优先级 `unread 蓝点 > running spinner > pinned 图钉`；ZCode 首项是 error 红点——我们无 error 态则如实不做）+ 元信息行（相对时间；变更 `+/-` 与 cron/月亮我们按数据面能取到才做）。
5. **任务行右键菜单**（Z-10 子集）：只做**我们能兑现的项**——置顶/取消、重命名、归档、标记未读、在分屏打开、查看 Model Trajectory；**跳过**「在文件管理器显示 / 复制日志路径 / 反馈」等无通道项（登记）。
6. **Footer**（Z-11 子集）：右侧设置齿轮（已有）；左侧 ZCode 是账号菜单——我们**无账号体系**，退化为「版本 + 设置」（登记差异）。

**不做（登记）**：Automations 按钮/视图、Plugin Store（不采纳）、文件树、账号登录/用量、Z-10 的无通道项。

## 2 关键约束

- **D-14（无渲染端持久化）**：ZCode 的侧栏偏好（视图模式/排序/折叠组）落 localStorage；我们**保持内存态**（与分屏布局同口径），不新增例外。**Pinned 走既有 session metadata 通道**（`updateMetadata` 已支持 title/archived/deleted → 加 `pinned` 字段，落 `desktop-metadata.json`），这是主进程持久化、不违反 D-14。
- **红线⑩**：无数据不渲染该分区/该项（Pinned 空则整区 return null）。
- **桌面 1115 用例零回归**；core/cli/gateway 零改动（除 metadata 形状若需加性扩展 desktop 侧）。
- 视觉只用语义 token + `text-ui-*`（Z-07 的 `h-8`/`h-12`/16px 槽位等尺寸按 refs 数值）。
