# ZCode 对照差距总账（2026-10-12，与官方 web 实测）

> 触发：用户实测反馈「UI 完全不一样、好多功能都没有」。此前 Z 程序的验收集中在**壳级指标**（token/几何/字体），覆盖窄——本总账是对**整个界面**的穷尽对照。
> 对照方式：`refs/ZCode` 源码权威清单（离线提取）+ **三个只读审计代理**对 ZCode 官方 web（`:5173`）与我们（`:5174`）的实测（见 §0 可信度声明）。
> 相关：`docs/ai-framework/plans/2026-10-12-phase-Z8-sidebar-ia.md`（侧栏已开工）· `docs/issue-log/2026-10-11.md` §43–§48。

## 0 可信度声明（重要——先读，避免误读本表）

| 限制                                                                                                                    | 影响                                                                                                          |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **子代理无法使用内置浏览器**（宿主拦截 `Browser is not available in subagent`），改用 Playwright headless Chromium 实测 | 结论基于真实 DOM/几何，但渲染引擎与 IAB 不同；**合成输入与真实 IME 行为可能有差**                             |
| **审计期间我们的 web 壳一度离线**（serve 被外部终止 → WS 502/401）                                                      | 凡「我们有/没有」的会话相关结论**不可靠**，本表已标注「未验」                                                 |
| **ZCode 官方 web 后端本身故障**（`SQLite startup failed: transport_closed`）                                            | 其**对话内容**（工具卡/思考块/审批/队列/状态面板）在参考端也加载失败 → 这类项**双向无法判定**                 |
| 审计对象是**我们的 web 壳**                                                                                             | 我们 **desktop 壳**的分区/功能多于 web 壳（如设置分区）；本表「我们」列以 web 壳为准，凡 desktop 更全处已注明 |

**结论口径**：本表只列**已实测**的差异；标「未验」的不计入差距判断。

## 2 待确认（需真机/真实数据）

- **composer 输入重复** ✅ 已定性（2026-10-12）：CDP 打字不复现（不走 composition 路径），但落盘事件里的逐字递减前缀链只有 IME composition 能产出 → **坐实为 IME 组合期缺陷**（`onBeforeInput` 只拦 `insertText` 放过 `insertCompositionText`；`onInput` 兜底不看 `isComposing` 中途回写）。修复执行中。
- **（2026-10-12 已证实并修复）core openai 流式 tool name 拼接缺陷**：真模型 E2E（用户提供的测试网关）钓出 `openai.ts` 对「每 chunk 重发完整工具名」的网关把 `bash` 累积成 `bashbash…` → 工具调用全败。已修（`a541f83`，`mergeToolCallName` 合并规则 + 回归测试）并 E2E 复验通过（bash 执行→审批 allow→结果→回复全链路绿）。**审批/工具卡/思考块/队列类「无法判定」项自此可实测**。
- 参考端后端故障导致的对话内容类项（见 §0）。
- 我们 web 壳离线下无法判定的项（右栏 tab 内容/拖拽/宽度、设置分区是否因数据缺失而隐藏）。
