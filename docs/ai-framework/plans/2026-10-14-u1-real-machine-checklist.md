# U1 真机验收清单（V6 · 交人类执行）

> 用法：U1 全部批次合入并由编排者跑完 V1-V5 后，你会拿到重新构建的 `packages/desktop/release/harness2-1.0.2-win-x64.exe`（或等 CI 产物）。安装前先用旧版对照回忆痛点，装后逐项打勾。任何一项不符，把「现象 + 时间点」记回 issue-log 当日文件即可，不用截图。

| #   | 项         | 操作                           | 期望                                                                                                                       |
| --- | ---------- | ------------------------------ | -------------------------------------------------------------------------------------------------------------------------- |
| M1  | 安装路径   | 双击安装包                     | 出现「选择安装位置」页；默认目录含 `harness2`（不是 `@harness2desktop`）                                                   |
| M2  | 启动       | 装完直接启动                   | 无「A JavaScript error occurred」弹窗（v1.0.1 已修，回归确认）                                                             |
| M3  | 空态窗控   | 冷启动不选任何会话             | 右上角可见 最小化/最大化/关闭 三键；三键全可用；拖动标题区能拖窗                                                           |
| M4  | 托盘       | 启动后看系统通知区             | 有 harness2 图标；**左键/双击=唤出主窗**；右键菜单=打开 harness2 ┃ 新建会话/添加项目 ┃ 导出日志 ┃ 退出                     |
| M5  | 关窗驻留   | 点关闭（X）                    | 窗口隐藏进托盘（默认开）；托盘右键「退出」才真退（任务管理器无残留 harness2 进程）                                         |
| M6  | 项目下新建 | 侧栏添加项目 → 悬浮项目行      | 出现「在此项目新建会话」；点击后新会话的 cwd=该项目目录（会话头/状态行可见路径）                                           |
| M7  | 删除会话   | 悬浮会话行 → 删除              | 有确认框；确认后列表消失；`~/.harness2/desktop-metadata.json` 出现该 id 的 `deleted:true`；重开应用不复活                  |
| M8  | 「+」延迟  | 点项目区「+」添加项目          | 系统目录框 ≤1s 出现在**前台**（不是沉到任务栏）；选完不超时不闪退                                                          |
| M9  | 发送反馈   | 断开网络/停掉网关后发消息      | 输入框上方出现错误横幅（含「查看详情/复制报错」），**草稿文字还在**                                                        |
| M10 | 长任务     | 让它跑一条慢命令（如全盘搜索） | 回合头「工作中 {时长}」实时走秒；工具行是扫光文案不是转圈；**Stop 按钮可点且能停**；停止后出现「已停止」终态，不再无限转圈 |
| M11 | 卡顿主观   | 正常聊天 + 拉历史长会话        | 输入与滚动无明显掉帧；流式输出期间输入框可打字                                                                             |
| M12 | 模型一致   | 配置 roles.main 后新建会话     | composer 模型选择器初值 = roles.main 的模型名                                                                              |

**回退口径**：若 M4/M5 引发问题（如某些杀软误报托盘行为），设置里「关闭窗口时隐藏到托盘」可关；关闭后回到旧行为（关窗=确认退出）。
