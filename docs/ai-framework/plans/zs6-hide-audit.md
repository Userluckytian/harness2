## 需处置清单（=T1 输入，附建议通道，优先级序）

1. **hooks 页「ZS1: not implemented」异常字面量渲染进 DOM**：读路径走 B 类 `plugin-management` 频道（channel-registry `classification: 'B'`），throw 文案被 UI 直接显示。处置=该频道的 hooks 读方法给最小真实实现（core `hooks/` 现成，列表+新建走真数据）；扩面过界则退为「空态形状+入口保留」。红线⑩最重违例（用户可见异常字符串），T1 首位。
2. **modelProvider 区 Z.ai 预设卡 + Start Plan 导航**：provider views 是我们 real 数据形状 → 视图生成时剔除 `preset:account:*`/`coding-plan:*` 条目（数据形状，零 patch）。
3. **usage 整分区**：section 列表来源查 services（feature-gate 或设置导航数据）→ 首选数据形状藏 nav；不行=装配点（分区注册在 ui 内则触发**人类门**）。
4. **remoteDevices「新建连接」**：同 3 逻辑，优先数据形状/能力位。
5. **Help 菜单外链族（问题上报/提交漏洞/提需求/产品文档/用户社群/检查更新）**：菜单在 desktop main `desktopApplicationMenu.ts` + `WorkspaceHelpMenuButton`（UI）双轨——UI 项若由 services feature 位驱动则数据形状；否则**desktop main 装配点 patch（P3 候选）**或人类门。资源管理器/导出日志/关于 保留（导出日志=ZS5 观测真实；「关于 ZCode」文案=品牌项归 T2）。
6. （条件项）plugin store browse 若实证走云 → 藏入口。
