## 遇到的问题与解法

（当日 `docs/issue-log/2026-09-10.md` 只登记了 R1 一项）

- **R1 · 一个被环境掩盖的假绿**：在 Git Bash 终端里跑测试一切正常，换到 PowerShell 5.1 立刻红。根因是 `packages/core/src/tools/shell.ts` 的 `gitBashCandidates()` 固定候选只覆盖 C 盘，而 PATH 分支只拼 `entry/bash.exe`——PATH 里通常只有 `...\Git\cmd`，`bash.exe` 在兄弟目录 `bin\`/`usr\bin\`。本机 Git 装在 `D:\Program Files\Git` 于是全部落空，一路回退 `cmd.exe`，`ls` 不是 cmd 内建 → exit 1。修法是对含 `/git/i` 的 PATH 条目同时探测 `entry`、`dirname/bin`、`dirname/usr/bin` 三处并去重；探测优先级（config > Git Bash > cmd）未动。
- **流程教训（当日留痕）**：Git Bash 终端自带 `...\Git\usr\bin`，恰好命中旧的 PATH 分支，所以缺陷被终端环境掩盖——**测试终端本身是变量**。R2 的注入式确定性用例与 R5 去掉 `--passWithNoTests` 都是为堵这一类「环境帮我绿了」。
